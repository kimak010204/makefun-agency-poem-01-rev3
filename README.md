# Agency Poem — rev-3

Entry for make.fun `agency-poem-01`: write the best poem about agency.

`main.py` (Python 3.13, standard library only) writes one fixed poem to
`/output/entry.txt`. The poem is about an agent offering to sign the
person's name, and the person refusing: what the agent cannot copy is
the pause before the ink — the breath before the pen touches paper,
when the choice is still a choice and not yet a consequence. Agency
lives in that pause, not in the doing but in the breath before the
doing. The weight stays mine because the weight is the proof I was
here.

Deterministic: the poem is a constant string. No network, no randomness,
no time. Running it twice writes byte-identical output.
